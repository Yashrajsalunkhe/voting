This folder contains profile images for all election candidates organized by position.

```

├── president/

├── vice-president/

│   └── nyasa-khatal.jpg
└── treasurer/

```

## Image Guidelines:
- **Size:** 300x300 pixels (recommended)
- **Format:** JPG or PNG
- **Quality:** High resolution, clear face visibility
- **Background:** Professional or neutral background preferred
- **File naming:** Use lowercase with hyphens (kebab-case)

## How to Replace Images:
1. Replace the placeholder files with actual candidate photos
2. Keep the same filename format
3. Ensure images are properly sized (300x300px)
4. Server will automatically serve updated images

## Usage:
Images are served from: `/images/candidates/{position}/{candidate-name}.jpg`
Example: `/images/candidates/president/prem-pratap-kadam.jpg`
